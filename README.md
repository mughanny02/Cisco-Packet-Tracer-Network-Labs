# Cisco Packet Tracer Network Labs

A collection of hands-on networking labs created using Cisco Packet Tracer to develop practical networking and IT support skills.

## Projects

### 1. AAA Server Demo
- Explores AAA (Authentication, Authorization, and Accounting) concepts in a simulated network environment.
- Documents network configuration and testing performed in the lab.

### 2. My First Network
- Demonstrates basic network topology and device connectivity.
- Provides hands-on practice with IP addressing and connectivity testing.

## Skills Practiced
- Network topology design
- IP addressing and configuration
- Network connectivity testing
- Troubleshooting and problem-solving

## Tools
- Cisco Packet Tracer

*Note: Project details reflect the configurations and features implemented in each lab.*
